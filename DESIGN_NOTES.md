1. The problem student services asked us to solve is to create a resource that students can look to in order to get answers to questions related to the college resources. Examples are information on the library, tutoring center, advising office, financial aid, and food pantry. We are to create an assistant that can answer basic questions or provide answers to what services are offered. The students should be able to interface with the assistant using plain English and expect accurate information.2. LLMs like Gemini can not answer campus-specific questions by itself because LLMs are not trained on private, local, or frequently changing information such as the campus directory.3. Three reasons the data is stored in a JSON file rather then inside the Python function are:   1. It separates data from logic, so code does not need to be edited to change information.   2. It makes the information independently reviewable so that information can be verified without understanding code.   3. It makes the project expandable as the JSON file can be replaced by a database, live API, or a content management system and the agent would not need to change.4. Three limitations are:   1. Data can become stale, the fix could be that a live database could be implemented therefore as long as the main website had accurate and up to date information the agent would as well.   2. The agent has no long-term memory of past conversations, session history could be saved in a database, or in the browser cache for a web interface.   3. The system is only as trustworthy as it's source data, need to ensure all data entered is verified by a person and updated/checked on a regular schedule. Ensure the agent returns an error instead of false information.5. If the campus information file is inaccurate it will only be able to return inaccurate information. This could cause trust in the assistant to drop off or never pick up, meaning that no one would use it. In that case no problems were solved and students would be left without access to resources. At this juncture we as the developers should be responsible for verifying it.|Resource|Location|Hours|Phone|Email|Website|Verified by|Date||-|-|-|-|-|-|-|-||Academic Advising|By appointment or virtual both by appointment|By appointment|716.338.1065|SuccessCenter@sunyjcc.edu|https://www.sunyjcc.edu/support/success-center/advising/get-connected|Sameer Patel|9/29/26||Career Services|Jamestown Campus, 525 Falconer Street, Jamestown, NY 14702||716.338.1061, 716.338.1381, 716.376.7584||https://www.sunyjcc.edu/support/career-services|Stavros Singleton|09-26-2026||Student Food Pantry|Jamestown Campus, next to the Campus Bookstore, Hamilton Collegiate Center, first floor; Cattaraugus County Campus, Success Center across from the bookstore, College Center, first floor||Jamestown Campus - 716.338.1004; Cattaraugus County Campus - 716.376.7508||https://www.sunyjcc.edu/support/get-help/food-pantry|Jerrica Sosa|9/22/26||Health Center|Jamestown Campus \| COCE 122; Cattaraugus County Campus \| COLL 139||716.338.1013 - Charlene Johnson (General); 716.338.1014 - Shelly Wells, RN (Nurse)|HealthCenter@sunyjcc.edu|https://www.sunyjcc.edu/support/health-center|Jerrica Sosa|9/22/26||Financial Aid \& Billing|COCE Floor 1, Jamestown Campus||716.338.1009|FinancialAid@sunyjcc.edu|https://www.sunyjcc.edu/support/financial-aid-billing|Tangie Cummings|9/29/26||IT Help Desk|Floor 1 of the Hultquist (HULT) building|Monday through Friday, 8:30 AM – 4:30 PM|716.338.1122|JCCHelpDesk@mail.sunyjcc.edu|https://jcc.helpdesk.sunyjcc.edu/servicedesk/customer/user/login?destination=portals|Shant Michaelian|9/26/26|
